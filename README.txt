VITAL BYTE - HTML & CSS WEBSITE PROJECT
=======================================

HOW TO OPEN THE WEBSITE
1. Extract the ZIP file to a folder on your computer.
2. Open the folder named Vital_Byte_TTSP.
3. Double-click index.html.
4. The website opens in your browser. Internet is not required.

PROJECT FILES
- index.html       Home page
- about.html       Company profile, history, mission and vision
- services.html    Telecom, power, internet and technical services
- projects.html    Illustrative project and activity areas
- packages.html    Sample internet packages
- login.html       Customer login form (visual demonstration)
- register.html    Customer registration form (visual demonstration)
- dashboard.html   Static sample customer dashboard and usage table
- resources.html   Customer guides and FAQ using HTML details/summary
- contact.html     Company contact details and enquiry form
- css/style.css    Shared stylesheet
- images/          Local SVG logo and illustrations

IMPORTANT NOTES FOR CLASS PRESENTATION
- This project uses HTML5 and CSS3 only. It does not use JavaScript.
- The forms are interface demonstrations. They do not create accounts, verify passwords,
  save data, send messages or process real purchases.
- The customer dashboard contains sample figures only; it does not read real internet usage.
- Package prices and data allowances are examples for the academic project.
- Project cards describe sample activity categories and are not a verified list of contracts.
- The company history date (1385 Solar Hijri), company name and contact details were
  supplied by the project owner.

CSS TOPICS USED
- box-sizing: border-box
- display: flex, flex-wrap, flex-direction
- justify-content and align-items
- flex shorthand and gap
- hover and focus pseudo-classes
- transition and transform
- box-shadow, border-radius and gradients
- media queries for responsive layouts
- HTML details and summary elements are styled through CSS
